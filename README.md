# Resort Management System (RMS)

## 1. Giới thiệu
Dự án xây dựng hệ thống quản lý Resort, hỗ trợ quản lý đặt phòng, khách hàng, dịch vụ và hoạt động vận hành.

## 2. Phương pháp phát triển
- Mô hình: Agile Scrum
- Công cụ quản lý dự án: GitHub
- Thời gian dự kiến: 4 tuần
- Số lượng Sprint: 4

## 3. Kế hoạch Sprint
- Sprint 1: 05/10/2026 – 11/10/2026
- Sprint 2: 12/10/2026 – 18/10/2026
- Sprint 3: 19/10/2026 – 25/10/2026
- Sprint 4: 26/10/2026 – 01/11/2026

## 5. Theo dõi công việc
Dự án sử dụng GitHub Issues để quản lý User Stories, Milestones để theo dõi các Sprint và Labels để phân loại, cập nhật trạng thái công việc.
